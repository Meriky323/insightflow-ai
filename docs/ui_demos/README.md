# InsightFlow UI Design Lab

Three visual directions were explored before selecting the final hybrid:

1. **Evidence Editorial** — warm editorial canvas, large typography, evidence threads. Selected base direction.
2. **Signal Lab** — dark analytical instrument, kinetic grid and luminous signal paths. Used selectively for hero/command moments.
3. **Field Notes** — paper/research-desk language, annotation marks, document rhythm. Used selectively for methodology/case-study tone.

The production site intentionally combines 1 + small amounts of 2/3 rather than copying any single reference.
