# InsightFlow AI 2.1.1：今日使用与验收

## 先区分两条使用路径

| 路径 | 用途 | 需要什么 |
| --- | --- | --- |
| 公开招聘演示 | 案例、证据筛选、机会、规则问答、报告导出 | 打开线上地址即可，无需 Key |
| 本地分析工作台 | 新研究、数据导入、实时采集、大模型分析 | Python；实时采集需 SerpAPI；AI 分析需兼容 Chat Completions 的有效模型接口 |

公开演示里的 Ask 是基于保存证据的规则回答，不是实时大模型推理。内置案例的消费者文本是已有来源摘要，不是逐字评论或本轮新抓取的数据。

## Windows 最短启动步骤

1. 解压整个项目。双击 `START_WINDOWS.bat`，首次启动会安装依赖，保留运行窗口。
2. 在浏览器打开 http://127.0.0.1:8000/ ，点击“查看旗舰案例”，进入工作台。
3. 打开“分析师工具 → 连接设置”。填写 SerpAPI Key，以及模型 Base URL、模型名、模型 Key。
4. 本地 Sub2API 通常为 `http://127.0.0.1:8080/v1`；模型名必须以自己账号可用的模型为准。
5. 先点“保存设置”，再重新打开连接设置，点“测试连接与 AI 生成”。这会做一次很短的模型生成调用。
6. 两项通过后，新建研究：关键词 `magnetic power bank`、US、快速。第一次只选一个来源，例如 YouTube，以便定位接口问题并控制用量。
7. 完成后检查证据数量、来源 URL、日期和分析模式，再尝试问答和导出。

不要把 Key 放进 GitHub 或公开演示。线上 Railway 无法访问你电脑的 localhost。

## 没有采集额度时仍能做真实 AI 分析

新建研究时取消所有在线来源，进入“消费者声音 → 导入 CSV / JSON”。导入自己实际收集、有出处的评论或调研数据。至少有 `text` 字段；建议同时提供 `source,url,review_date,market`。无法确认作者国家时填 `GLOBAL`。已配置有效模型接口后，导入会触发结构化分析。

`examples/evidence_import_template.csv` 是格式示例。不要把格式示例或测试夹具当真实业务证据。

## 这次修复什么

- 合并旧 2.0 包中遗漏的 YouTube 评论分页 token 修复，保留 2.1 的社区检索和问答检索能力。
- 修正前后端 YouTube 与社区检索调用次数估算。
- 修复证据覆盖矩阵遗漏 GLOBAL 列、导入后列表不刷新。
- 标明内置案例文本为来源摘要；公开 Ask 与模型失败回退均明确标识为规则回答。
- 修正首页预览数量、失效的工作流锚点，并给案例加载增加反馈与重复点击保护。
- 机会优先级显示排名；分值仍可用于内部排序，不当作市场规模。
- 连接测试新增真正生成检查；启动失败保留错误信息。

## 已验证与待验证的边界

本轮离线自动化验证覆盖：案例加载、证据来源与日期标识、跨市场比较限制、公开模式隔离、CSV 导入与去重、搜索过滤、PDF/CSV/DOCX 导出、模型请求格式、模拟采集流程。模拟测试数据仅存在于测试夹具中。

付费采集和真实模型生成需要在你配置的环境中完成最终验收。本轮没有获取你的 SerpAPI/Sub2API 凭据，不能把接口协议测试描述为真实付费调用成功。

已有来源摘要的外链和逐条内容未在本轮重新进行事实核验；链接存在不等于摘要已经复核。不要把 18 条摘要称作 18 名独立受访者，也不要将其样本比例外推为消费者总体比例。

影石案例是已有静态业务假设页，不是已运行的第二套实时研究；简历先使用磁吸充电宝案例即可。

## 90 秒面试演示

1. 说明业务问题：同质化磁吸充电宝如何确定优先验证的产品与传播卖点。
2. 查看“便携与轻薄”证据，解释来源、摘要与原文的区别。
3. 进入机会看板：把观察转成产品动作、GTM 动作和下一步验证。
4. 演示为什么系统拒绝 US/AU 消费者偏好比较。
5. 导出证据或 Brief，说明如何交给业务团队继续验证。

## 简历可用的保守版本

**InsightFlow AI｜海外消费者洞察与 GTM 决策工具｜独立项目**

- **业务问题定义：** 围绕出海硬件新品定位与内容选题，将消费者反馈拆解为购买驱动、使用阻碍与场景需求，设计“证据—洞察—产品/GTM 动作—验证计划”的分析流程。
- **产品落地：** 借助 AI 编程搭建双语研究工作台，支持 CSV/JSON 导入、证据去重与来源追溯、主题筛选、机会排序及 PDF/CSV 报告导出，接入可配置的大模型结构化分析接口。
- **案例与研究边界：** 以磁吸充电宝为示例，组织 18 条本期来源摘要、14 条基线摘要及 8 条商品信号，形成轻薄性、热稳定性和设备适配等验证假设；保留 GLOBAL 地域标识，限制证据不足的跨市场结论。

真实接口验收通过后，才将“可配置接口”改为“完成实时采集与 AI 分析联调”。不写不存在的业务增长、准确率、节省工时或企业使用量。
