# InsightFlow v1.5 — Recruiting conversion pass

This release intentionally freezes the core research engine and improves recruiting conversion instead of adding more crawlers.

## Added
- Target-company application case: **Insta360 X6 Launch Intelligence**
- A second-category proof that InsightFlow generalizes beyond magnetic power banks
- Evidence-backed launch decision: workflow / time-to-share as a GTM battleground
- Explicit launch-sample confidence boundary
- Target-case section on recruiter landing page
- Recruiting application playbook and interview path

## Not added
- No new TikTok / Instagram crawler
- No speculative sales forecast
- No fake market-wide sentiment
- No unsupported country comparison

## Why
The highest-value next step for autumn recruiting is to demonstrate that the same evidence discipline can be applied to a target company's real product decision, not to increase technical feature count.
