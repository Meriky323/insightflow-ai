# Public recruiter deployment checklist

Recommended Railway environment:

```env
PUBLIC_DEPLOYMENT=1
ALLOW_PUBLIC_LIVE_RESEARCH=0
```

Before sharing the link:

1. Open `/` in a private/incognito browser.
2. Confirm **Explore the flagship case** opens without any API key.
3. Confirm Settings, live research and uploads are not exposed publicly.
4. Confirm `Ask InsightFlow` answers in local evidence-grounded mode.
5. Open Consumer Voice and click at least two evidence links.
6. Open Market Comparison and confirm unsupported US/AU consumer preference comparison is blocked.
7. Download the PDF brief and Evidence CSV once.
8. Open `/case-study.html` on desktop and mobile.
9. Add the final URL to GitHub README and resume/portfolio.

Do not publish your local `.env`, SerpApi key or Sub2API key.
