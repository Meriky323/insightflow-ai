INSIGHTFLOW LIVE WEBSITE DEPLOYMENT

Resume URL:
https://insightflow-ai.up.railway.app/

What this package does:
- Replaces the old Railway/GitHub version with the recruiter-ready v1.5 website.
- Keeps the landing page, flagship Magnetic Power Bank case, and Insta360 X6 target-company case in one live website.
- Automatically treats Railway as public recruiter mode, even if PUBLIC_DEPLOYMENT was not manually configured.
- Keeps live API-consuming research, connector settings, uploads and paid LLM quota protected in Railway public mode.

To publish:
1. Extract this ZIP.
2. Double-click DEPLOY_LIVE_WEBSITE.bat.
3. If GitHub opens a sign-in page, approve it once.
4. The script pushes to GitHub main and waits for Railway auto-deploy.
5. When SUCCESS appears, the resume URL is updated.

No force push is used.
